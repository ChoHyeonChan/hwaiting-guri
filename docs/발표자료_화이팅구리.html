개발 중 창업팀 명세를 공식 정정시켰습니다

1. 실행 출력에서 불일치를 발견

DOC-020의 예외 플래그 개수가 명세 요약표와 규칙 조항에서 서로 달랐습니다. 우리 구현은 조항을 따라 2개로 판정하고 있었습니다.

2. 근거와 함께 질의

추측이 아니라 실제 실행 출력 + 근거 조항을 함께 첨부해 문의했습니다. 어느 쪽이 맞는지가 아니라, 무엇이 어긋나 있는지를 보였습니다.

3. 전체 팀 공지로 정정

창업팀이 명세를 정정하고 전체 참가팀에 공지했습니다. 우리 구현은 이미 맞아 코드 수정은 없었고, 권장사항만 반영했습니다.

창업팀 공지 인용
"한 참가팀이 실제 구현 출력과 근거 조항을 함께 보내주셔서 확인됐습니다."

문서를 읽고 구현하는 데서 멈추지 않고, 구현 결과로 문서를 검증했습니다. 같은 방식으로 개발 중 우리 결함도 스스로 찾아 고쳤습니다 — 백업이 지워지던 문제, 검수 메모가 저장되지 않던 문제, 승인 뒤 값을 깨뜨려도 승인이 유지되던 문제.
